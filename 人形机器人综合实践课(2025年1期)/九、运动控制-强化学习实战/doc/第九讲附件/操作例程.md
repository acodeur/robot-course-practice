## 一、Unitree RL Lab 环境搭建

### 1.1 克隆并安装

```bash
# 确认环境为已安装issac lab的解释器
conda env list

# 克隆
cd ~
git clone https://github.com/unitreerobotics/unitree_rl_lab.git

# 安装
cd unitree_rl_lab/
./unitree_rl_lab.sh -i
```

### 1.2 下载机器人描述文件

```bash
cd ~
git clone https://huggingface.co/datasets/unitreerobotics/unitree_model
```

### 1.3 配置模型路径

```bash
vim ~/unitree_rl_lab/source/unitree_rl_lab/unitree_rl_lab/assets/robots/unitree.py
```

1. `/UNITREE_MODEL_DIR` 回车
2. 把路径改成 `/root/unitree_model`
3. `Esc` → `:wq` 回车

### 1.4 验证安装

```bash
cd ~/unitree_rl_lab/
./unitree_rl_lab.sh -l
```

确认输出中包含 `Unitree-G1-29dof-Velocity` 等 5 个任务。

### 1.5 启动训练

```bash
cd ~/unitree_rl_lab/
./unitree_rl_lab.sh -t --task Unitree-G1-29dof-Velocity
```

### 1.6 TensorBoard 可视化（新开终端）

```bash
tensorboard --logdir ~/unitree_rl_lab/logs/rsl_rl/unitree_g1_29dof_velocity/
```

浏览器打开 `http://localhost:6006`。

## 二、Sim2Sim 部署依赖安装

```bash
sudo apt update
sudo apt install libyaml-cpp-dev libboost-all-dev libeigen3-dev libspdlog-dev libfmt-dev
```

### 2.2 安装 unitree_sdk2 C++ SDK

```bash
cd ~
git clone https://github.com/unitreerobotics/unitree_sdk2.git
```

## 三、ONNX 模型导出与配置

### 3.1 查找训练 checkpoint

```bash
ls ~/unitree_rl_lab/logs/rsl_rl/unitree_g1_29dof_velocity/
```

进入具体的 run 目录，查看 checkpoint：

```bash
ls ~/unitree_rl_lab/logs/rsl_rl/unitree_g1_29dof_velocity/<run时间戳>/
```

选择数字最大的 `model_*.pt`。

### 3.2 导出 ONNX

```bash
cd ~/unitree_rl_lab
./unitree_rl_lab.sh -p \
  --task Unitree-G1-29dof-Velocity \
  --num_envs 4 \
  --checkpoint "/root/unitree_rl_lab/logs/rsl_rl/unitree_g1_29dof_velocity/<run时间戳>/model_<最大迭代数>.pt"
```

导出后在 run 目录下确认生成了 `exported/policy.onnx` 和 `params/deploy.yaml`：

```bash
ls <run时间戳>/exported/
ls <run时间戳>/params/
```

### 3.3 部署模型文件到 g1_ctrl

将训练 run 目录下导出的 `exported/policy.onnx` 和 `params/deploy.yaml`，复制到 g1_ctrl 的部署目录：

```
源：~/unitree_rl_lab/logs/rsl_rl/unitree_g1_29dof_velocity/<run时间戳>/
目标：~/unitree_rl_lab/deploy/robots/g1_29dof/config/policy/velocity/v0/
```

### 3.4 配置 MuJoCo 仿真器

```bash
vim ~/unitree_mujoco/simulate/config.yaml
```

修改以下字段：

| 字段                    | 修改为    |
| --------------------- | ------ |
| `robot`               | `"g1"` |
| `domain_id`           | `0`    |
| `enable_elastic_hand` | `1`    |
| `use_joystck`         | `1`    |

### 3.5 配置键盘控制

**3.5.1 修改 deploy.yaml**

```bash
vim ~/unitree_rl_lab/deploy/robots/g1_29dof/config/policy/velocity/v0/params/deploy.yaml
```

找到 `velocity_commands` 部分，注释掉，并改成 `keyboard_velocity_commands`：

```yaml
# velocity_commands:

keyboard_velocity_commands:
```

**3.5.2 修改 CtrlFSM.h**

将课程提供的 `CtrlFSM.h` 替换到以下路径：

```bash
cp ~/CtrlFSM.h ~/unitree_rl_lab/deploy/include/FSM/CtrlFSM.h
```

**3.5.3 重新编译**

```bash
cd ~/unitree_rl_lab/deploy/robots/g1_29dof/build
make -j4
```

> 如果报 `'FSMState' has not been declared`，再跑一次 `make -j4`。

## 四、MuJoCo Sim2Sim 部署运行

### 4.1 启动 MuJoCo 仿真器（终端 1）

```bash
cd ~/unitree_mujoco/simulate/build
./unitree_mujoco
```

MuJoCo 窗口弹出，机器人悬空。**点击 MuJoCo 窗口使其获得焦点**，按住 `8` 慢慢放下机器人，双脚触地后松开。

### 4.2 启动 g1_ctrl 控制器（终端 2）

```bash
cd ~/unitree_rl_lab/deploy/robots/g1_29dof/build
./g1_ctrl --network lo
```

机器人自动站起来。回到 **MuJoCo 窗口**按 `9` 松开弹性带。

### 4.3 键盘控制

**在 g1_ctrl 终端中按键**（点击 g1_ctrl 终端使其获得焦点）：

**速度控制：**

| 按键 | 效果 |
|------|------|
| `W` | 前进 |
| `S` | 后退 |
| `A` | 左转 |
| `D` | 右转 |
| `Q` | 左平移 |
| `E` | 右平移 |
| `Y` | 侧倾 |
| 松开所有键 | 停止 |

**状态切换：**

| 按键 | 切换到 |
|------|--------|
| `1` | Passive（被动） |
| `2` | FixStand（站立） |
| `3` | Velocity（行走） |
| `8` | Mimic_Dance（舞蹈） |
| `9` | Mimic_Gangnam（骑马舞） |

> ⚠️ **MuJoCo 窗口的 `8`/`9` 是控制弹性带，g1_ctrl 终端的 `8`/`9` 是切换舞蹈状态，不要混淆。**

### 4.4 操作流程总结

```
终端 1：./unitree_mujoco          → 机器人悬空
         ↓
MuJoCo 窗口按住 8                 → 放到地面后松开
         ↓
终端 2：./g1_ctrl --network lo    → 机器人自动站立
         ↓
MuJoCo 窗口按 9                   → 松开弹性带
         ↓
g1_ctrl 终端：W/A/S/D/Q/E/Y       → 控制移动
         ↓
g1_ctrl 终端：8                   → 切换舞蹈模式
```
