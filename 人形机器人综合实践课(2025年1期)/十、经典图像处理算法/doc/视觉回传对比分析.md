# 视觉回传对比分析
Aelos SMART机器人通过硬件摄像头、树莓派操作系统、网络/USB传输将视频流回传到PC上。
Aelos SMART自带的视觉回传功能与课程讲解的图像处理流程相比，

- 相同点：
二者都遵循"读取图片 → 预处理（滤波）→ 颜色空间转换 → 阈值分割 → 形态学处理 → 轮廓提取 → 输出结果"这条经典流程，都将彩色图转换到HSV这样色相与亮度解耦的空间。
- 不同点：
**阈值确定方式不同**：课程代码里HSV_LOWER/UPPER是手写常量，需要一次次调参；Aelos SMART客户端为"红/橙/黄/绿/蓝"等预设颜色内置好了阈值，此外通过取色笔可以快速确定目标所在阈值大致范围避免多次调参。
**运行环境不同**：课程demo完全在本地Python进程内完成；Aelos SMART的视觉回传通过网络通信或者USB完成。
**后处理不同**：Aelos SMART用积木把"识别到红色"作为触发条件，可以直接联动动作库；课程demo仅止于画框，后续"识别→控制"需要自行实现。
