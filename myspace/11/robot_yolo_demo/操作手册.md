# 操作手册：YOLO 目标检测推理

本节课目标：搭建 YOLO 推理环境，使用已经训练好的 `yolo11n.pt` 模型，对图片运行目标检测，并读取输出结果：

```text
class_name / confidence / bbox_xyxy
```

---

## 一、本节课要完成什么

本节课的操作路线是：

```text
准备资料包
    ↓
安装 Miniconda
    ↓
创建 robot_yolo 环境
    ↓
安装 ultralytics
    ↓
运行 YOLO 单图推理
    ↓
查看检测结果图
    ↓
运行 Python 脚本读取检测结果
```

## 三、安装 Miniconda

下载安装脚本：

```bash
cd ~
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
```

给安装脚本增加可执行权限：

```bash
chmod +x Miniconda3-latest-Linux-x86_64.sh
```

运行安装脚本：

```bash
./Miniconda3-latest-Linux-x86_64.sh
```

安装时按提示操作：

```text
按 Enter 阅读许可协议
输入 yes 接受协议
安装路径默认即可
询问 conda init 时输入 yes
```

安装完成后，刷新终端配置：

```bash
source ~/.bashrc
```

或者关闭终端后重新打开。

为了避免以后打开终端时自动进入 `(base)` 环境，执行：

```bash
conda config --set auto_activate false
```

检查设置：

```bash
conda config --show auto_activate
```

如果看到：

```text
auto_activate: False
```

说明设置成功。

检查 conda 是否可用：

```bash
conda --version
```

能看到类似下面的版本号即可：

```text
conda 25.x.x
```

## 四、创建 YOLO 环境

先接受 Anaconda 默认软件源的 Terms of Service。新版 Miniconda 第一次创建环境时可能需要这一步：

```bash
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
```

创建 `robot_yolo` 环境：

```bash
conda create -n robot_yolo python=3.10 -y
```

激活环境：

```bash
conda activate robot_yolo
```

激活成功后，终端前面通常会出现：

```text
(robot_yolo)
```

检查 Python 版本：

```bash
python --version
```

应看到：

```text
Python 3.10.x
```

如果看到 `Python 3.13.x` 或其他版本，先不要继续，执行：

```bash
conda info --envs
```

确认是否已经进入 `robot_yolo` 环境。

## 五、安装 Ultralytics

`ultralytics` 是调用 YOLO 的 Python 工具包。它可以帮我们加载 `yolo11n.pt`，对图片做推理，并输出检测结果。

在 `(robot_yolo)` 环境中执行：

```bash
pip install ultralytics
```

安装完成后检查：

```bash
yolo checks
```

如果能看到环境检查信息，说明 YOLO 工具可以正常运行。

## 七、认识 YOLO 标签格式

打开标签样例：

```bash
cat labels/football.txt
```

YOLO 标签一行通常是：

```text
class_id x_center y_center width height
```

含义：

| 字段 | 含义 |
|---|---|
| `class_id` | 类别编号，从 0 开始 |
| `x_center` | 检测框中心点的横坐标 |
| `y_center` | 检测框中心点的纵坐标 |
| `width` | 检测框宽度 |
| `height` | 检测框高度 |

## 八、运行 YOLO 单图推理

确认当前目录：

```bash
pwd
```

应在：

```text
/home/你的用户名/robot_yolo_demo
```

运行单张图片推理：

```bash
yolo predict model=models/yolo11n.pt source=images/soccer_practice_field.png conf=0.25 project=outputs name=cli_predict exist_ok=True
```

参数说明：

| 参数 | 含义 |
|---|---|
| `model=models/yolo11n.pt` | 使用资料包里的 YOLO11n 权重 |
| `source=images/soccer_practice_field.png` | 输入图片 |
| `conf=0.25` | 只保留置信度大于 0.25 的结果 |
| `project=outputs` | 输出项目名；当前 Ultralytics CLI 会把结果保存到 `runs/detect/outputs/` 下 |
| `name=cli_predict` | 本次结果文件夹名称 |
| `exist_ok=True` | 如果文件夹已存在，允许继续写入 |

运行成功后，结果通常保存在：

```text
runs/detect/outputs/cli_predict/
```

如果你的终端最后一行 `Results saved to ...` 显示了其他路径，请以终端实际输出为准。

---

## 九、查看检测结果

查看输出目录：

```bash
ls runs/detect/outputs/cli_predict
```

手动打开文件夹：

```text
robot_yolo_demo/runs/detect/outputs/cli_predict
```

查看结果时重点关注：

- 图片上是否有检测框。
- 检测类别是否合理。
- 置信度越高，表示模型越确信这个检测结果。

## 十、运行 Python 脚本读取检测结果

CLI 命令适合快速看结果图。Python 脚本可以读取程序中的检测数据。

运行脚本：

```bash
python scripts/detect_image.py
```

输出：

```text
image: images/soccer_practice_field.png
detections: 2
--------------------------------------------------------------------------------
[0] class_name=sports ball
    confidence=0.959
    bbox_xyxy=(602.7, 416.7, 976.5, 786.1)
[1] class_name=person
    confidence=0.906
    bbox_xyxy=(150.7, 0.8, 615.4, 641.6)
--------------------------------------------------------------------------------
visual result saved to: outputs/python_predict
```

输出字段说明：

| 字段 | 含义 |
|---|---|
| `class_name` | 模型识别出的类别名称 |
| `confidence` | 置信度，越接近 1 越确信 |
| `bbox_xyxy` | 检测框坐标，格式为 `(x1, y1, x2, y2)` |

`bbox_xyxy` 表示：

```text
x1, y1：检测框左上角
x2, y2：检测框右下角
```

## 十一、常见问题

### 1. `conda: command not found`

处理：

```bash
source ~/.bashrc
```

或者关闭终端后重新打开。

### 2. `Permission denied`

如果执行安装脚本时报错：

```text
Permission denied
```

处理：

```bash
chmod +x Miniconda3-latest-Linux-x86_64.sh
./Miniconda3-latest-Linux-x86_64.sh
```

### 3. `CondaToSNonInteractiveError`

说明还没有接受 Anaconda 软件源条款。处理：

```bash
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
```

然后重新创建环境：

```bash
conda create -n robot_yolo python=3.10 -y
```

### 4. `EnvironmentNameNotFound`

如果看到：

```text
Could not find conda environment: robot_yolo
```

说明 `robot_yolo` 环境还没有创建成功。先检查：

```bash
conda info --envs
```

如果列表里没有 `robot_yolo`，重新执行创建环境命令。

### 5. `yolo: command not found`

通常是没有进入 `robot_yolo` 环境，或没有安装 `ultralytics`。

处理：

```bash
conda activate robot_yolo
python -m pip show ultralytics
```

如果没有显示安装信息：

```bash
pip install ultralytics
```

### 6. 找不到模型或图片

先确认当前目录：

```bash
pwd
```

应在：

```text
~/robot_yolo_demo
```

再检查：

```bash
ls models
ls images
```

确认 `yolo11n.pt` 和输入图片确实存在。

### 7. Python 脚本提示 `outputs/python_predict` 权限不足

如果运行：

```bash
python scripts/detect_image.py
```

或在 `scripts` 目录下运行：

```bash
python3 detect_image.py
```

出现类似错误：

```text
PermissionError: [Errno 13] Permission denied: '/home/ycy/robot_yolo_demo/outputs/python_predict'
```

通常说明 `outputs` 目录权限不正常。目录除了读写权限，还需要 `x` 权限；对目录来说，`x` 表示允许进入这个目录、访问目录里面的内容。

先检查：

```bash
cd ~/robot_yolo_demo
ls -ld outputs
```

如果看到类似：

```text
drw-rw-r-- 2 ycy ycy 4096 May  9  2026 outputs
```

说明 `outputs` 目录缺少 `x` 权限。修复：

```bash
cd ~/robot_yolo_demo
chmod -R u+rwX outputs
```

然后重新运行：

```bash
python scripts/detect_image.py
```

说明：这里的 `X` 是大写，表示给目录增加进入权限，不会给普通文件增加可执行权限。
